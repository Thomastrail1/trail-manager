# 🏔️ Trail Manager

> De coureur amateur à légende de l'ultra-trail.

Trail Manager est un jeu mobile de gestion et de simulation de carrière dans le monde du trail running.

## 🎮 Concept

Le joueur crée son coureur et gère :

- 🏃 Entraînement
- ❤️ Forme et fatigue
- 🥗 Nutrition
- 🎒 Équipement
- 🏔️ Courses
- 🧠 Stratégie
- 🏆 Classements
- 💰 Carrière et sponsors
